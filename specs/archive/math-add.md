# `add` の追加

2 つの数の和を返す `add` を公開する。

## 種別

機能追加

## 対象

- 場所: 算術ライブラリ
- 公開面: `add(a, b) -> number`

## 背景

和を返す公開関数が無い。四則演算の起点として、2 つの有限数を足す操作が必要である。

## 仕様

```
add(a, b) -> number
```

- `a`: 加数。有限数
- `b`: 加数。有限数
- 戻り値: `a` と `b` の和。有限数
- 純関数。引数を変更しない。
- `a` と `b` は IEEE 754 の有限数である。`NaN` および `Infinity` は受け取らない。
- 戻り値は `a + b` に等しい。
- 交換法則が成り立つ: `add(a, b)` と `add(b, a)` は等しい。
- `0` は単位元である: `add(a, 0)` と `add(0, a)` は `a` に等しい。

## 範囲外

- `NaN` / `Infinity` の扱い
- 3 引数以上の和

## 失敗時

なし。

## 例

| 操作または入力 | 期待結果 |
|---|---|
| `add(2, 3)` | `5` |
| `add(-1.5, 0.5)` | `-1` |
| `add(0, 0)` | `0` |
| `add(-4, -6)` | `-10` |

## 完了条件

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. 交換法則が成り立つ。`0` が単位元である。引数を変更しない。
