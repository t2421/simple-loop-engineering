# `mul` の追加

2 つの数の積を返す `mul` を公開する。

## 種別

機能追加

## 対象

- 場所: 算術ライブラリ
- 公開面: `mul(a, b) -> number`

## 背景

積を返す公開関数が無い。`add` と `sub` に続く四則演算として、2 つの有限数を掛ける操作が必要である。

あわせて、`specs/parallel-worktrees.md` の演習対象として `math-div` と並列に実施する。両者は `src/math.mjs` の別々の関数を足すだけで互いに依存しない。

## 仕様

```
mul(a, b) -> number
```

- `a`: 乗数。有限数
- `b`: 乗数。有限数
- 戻り値: `a` と `b` の積。有限数
- 純関数。引数を変更しない。
- `a` と `b` は IEEE 754 の有限数である。`NaN` および `Infinity` は受け取らない。
- 戻り値は `a * b` に等しい。
- 交換法則が成り立つ: `mul(a, b)` と `mul(b, a)` は等しい。
- `1` は単位元である: `mul(a, 1)` と `mul(1, a)` は `a` に等しい。
- `0` は吸収元である: `mul(a, 0)` と `mul(0, a)` は `0` に等しい。

## 範囲外

- `NaN` / `Infinity` の扱い
- 3 引数以上の積
- 桁あふれ（`Number.MAX_VALUE` 超過）の扱い

## 失敗時

なし。

## 例

| 操作または入力 | 期待結果 |
|---|---|
| `mul(2, 3)` | `6` |
| `mul(-1.5, 4)` | `-6` |
| `mul(0, 7)` | `0` |
| `mul(-4, -6)` | `24` |

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. 交換法則が成り立つ。`1` が単位元、`0` が吸収元である。引数を変更しない。
