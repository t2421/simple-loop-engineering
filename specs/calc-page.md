# 計算ページの追加

2 つの数値入力と加減の選択から、計算ボタンで結果を表示する HTML ページを公開する。

## 種別

機能追加

## 対象

- 場所: 計算 UI（HTML ページ）
- 公開面: 入力 2 欄、加減の選択、計算ボタン、結果表示

## 背景

`add` と `sub` は公開済みだが、ブラウザから使う画面が無い。見た目の正は次の Figma フレームとする。

- ファイル: [sample-loop-engineering](https://www.figma.com/design/KHrUQrYl0Motmr2nyyEOrB/sample-loop-engineering?node-id=1-2)
- file key: `KHrUQrYl0Motmr2nyyEOrB`
- node id: `1:2`

抽出結果は `progress/calc-page.figma.json` と `progress/calc-page.png` に置く。抽出後はテストを通すために書き換えない。

## 仕様

### 構造と操作

- 数値を入力できる欄が 2 つある
- UI で足し算と引き算を選択できる
- 計算ボタンを押すと、選択した計算方法の結果が表示される
- 足し算は既存の `add(a, b)`、引き算は既存の `sub(a, b)` を呼ぶ
- 結果は選択した関数の戻り値を表示する

### 見た目

- トークンと幾何の正は `progress/calc-page.figma.json`（ノード `1:2` から抽出したプロパティ）
- 参照画像の正は `progress/calc-page.png`（同じノードの書き出し）
- 実装は CSS 変数でトークンを参照し、表に無いマジックナンバーを置かない
- 比較するプロパティは塗り、文字色、フォントサイズ、フォントウェイト、パディング、ギャップ、角丸、幅・高さとする

## 範囲外

- 掛け算・割り算
- `NaN` / `Infinity` の扱い
- ピクセル完全一致（差分 0）

## 失敗時

なし。

## 例

| 操作または入力 | 期待結果 |
|---|---|
| 左 `2`、右 `3`、足し算、計算 | 結果が `5` |
| 左 `5`、右 `3`、引き算、計算 | 結果が `2` |
| 左 `-1.5`、右 `0.5`、足し算、計算 | 結果が `-1` |
| 左 `0`、右 `0`、引き算、計算 | 結果が `0` |

## 完了条件

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. 計算は `add` / `sub` を使う。抽出済みの `progress/calc-page.figma.json` の比較対象プロパティと、対象要素の計算スタイルが一致する。`progress/calc-page.png` とのピクセル不一致率は 0.5% 以下である。
