# `div` の追加

2 つの数の商を返す `div` を公開する。

## 種別

機能追加

## 対象

- 場所: 算術ライブラリ
- 公開面: `div(a, b) -> number`

## 背景

商を返す公開関数が無い。`add` と `sub` に続く四則演算として、2 つの有限数を割る操作が必要である。除数 0 という、これまでの三演算に無い失敗条件を持つ。

あわせて、`specs/parallel-worktrees.md` の演習対象として `math-mul` と並列に実施する。両者は `src/math.mjs` の別々の関数を足すだけで互いに依存しない。

## 仕様

```
div(a, b) -> number
```

- `a`: 被除数。有限数
- `b`: 除数。0 でない有限数
- 戻り値: `a` を `b` で割った商。有限数
- 純関数。引数を変更しない。
- `a` と `b` は IEEE 754 の有限数である。`NaN` および `Infinity` は受け取らない。
- 戻り値は `a / b` に等しい。
- `1` は右単位元である: `div(a, 1)` は `a` に等しい。
- 同じ数同士の商は `1` である: `b` が 0 でないとき `div(b, b)` は `1` に等しい。
- 交換法則は成り立たない: `a` と `b` が異なり、いずれも 0 でないとき `div(a, b)` と `div(b, a)` は等しくない。
- `b` が `0` のとき `RangeError` を投げる。`Infinity` や `NaN` を返さない。

## 範囲外

- `NaN` / `Infinity` を引数に取る場合の扱い
- 3 引数以上の商
- 剰余（`mod`）

## 失敗時

- `b` が `0`: `RangeError` を投げる。メッセージに 0 で割れない旨を含める

## 例

| 操作または入力 | 期待結果 |
|---|---|
| `div(6, 3)` | `2` |
| `div(-6, 1.5)` | `-4` |
| `div(0, 5)` | `0` |
| `div(-4, -8)` | `0.5` |
| `div(1, 0)` | `RangeError` を投げる |
| `div(0, 0)` | `RangeError` を投げる |

## 完了条件

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. `1` が右単位元である。`div(b, b)` が `1` である。除数 0 で `RangeError` を投げる。引数を変更しない。
