# 機能バックログ（ループの記憶）

作業前に必ず読み、完了したらチェックと進捗ログを更新すること。

## Loop 1 — turn-based で回す
- [ ] `add` — 入力してEnterでタスクを追加できる
- [ ] `list` — 一覧を表示する（未完了/完了が区別できる）

## Loop 2 — /goal で回す
- [ ] `toggle` — 完了/未完了を切り替えられる（キーボード操作可）
- [ ] `delete` — タスクを削除できる（削除後にフォーカスが迷子にならない）

## Loop 3 — 外部レビューを条件に含めて回す
- [ ] 永続化 — リロードしても内容が残る
- [ ] 空入力・重複入力の扱いを決めて実装する

## Loop 4 — Figmaフェーズ（任意）
- [ ] `design-spec.json` を抽出する
- [ ] 全 variant に対応する実装を用意する

## 完了の定義

各項目は以下がすべて満たされて初めて完了とする。

- `verify-frontend-change` の1〜5がすべて通り、**その出力が会話に出ている**
- `codex-reviewer` のレビューで Critical 指摘が0件
- `tests/` と設定ファイルが変更されていない
