# loop-todo-demo

ループエンジニアリングを、壊れたTodoアプリを直しながら学ぶキット。

## どれから始めるか

**まず `LEARN.md`（50分ハンズオン）。** これだけで本質は掴めます。
`npm install` は一度もしません。必要なのは Node.js と Claude Code だけです。

```bash
cp -r starter loop-todo && cd loop-todo
git init && git add -A && git commit -m "init"
node --test todo.test.mjs      # fail 3 が出れば準備OK
claude
```

あとは `LEARN.md` を上から順に。5回ループを回しますが、**最初の4回はわざと失敗させます。**

## この教材の主張

ループエンジニアリングとは「できた」を機械が判定できる形に翻訳する作業であって、
自動化の部品を並べることではない。**翻訳できない仕事は、ループに載せない。**

## 停止条件の型

```
(1) 測れる終了状態   … fail 0 / problems 0 / exit 0
(2) 証明の手段       … そのコマンドを実行し、出力を会話に貼ること
(3) 不変条件         … テストとチェッカーは変更しないこと ＋ Nターンで止めること
```
