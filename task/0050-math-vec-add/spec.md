# `addVec` の追加

2 次元ベクトルの和を返す `addVec` を公開する。

## 種別

機能追加

## 対象

- 場所: 算術ライブラリ（`src/math.mjs`）
- 公開面: `addVec(a, b) -> [number, number]`

## 背景

算術ライブラリにはスカラーの `add` / `sub` / `mul` / `div` があるが、ベクトル演算が無い。2 次元ベクトルの足し算を UI から呼ぶために公開関数が必要である（`0051-calc-vec-add` が使う）。

## 仕様

```
addVec(a, b) -> [number, number]
```

- `a`: 加数のベクトル。長さ 2 の配列。各要素は IEEE 754 の有限数
- `b`: 加数のベクトル。長さ 2 の配列。各要素は IEEE 754 の有限数
- 戻り値: 新しい配列 `[a[0] + b[0], a[1] + b[1]]`
- 純関数。引数を変更しない。入力配列 `a`・`b` はそのまま残る
- 戻り値は入力とは別の新しい配列である（`a` や `b` を返さない）
- `NaN` および `Infinity` は要素として受け取らない（既存 `add` と同じ前提）
- 交換法則が成り立つ: `addVec(a, b)` と `addVec(b, a)` は要素ごとに等しい
- ゼロベクトル `[0, 0]` は単位元である: `addVec(a, [0, 0])` と `addVec([0, 0], a)` は `a` と要素ごとに等しい

## 範囲外

- 3 次元以上・可変長のベクトル
- オブジェクト形式 `{x, y}` の入力
- `NaN` / `Infinity` 要素の扱い（テストもしない）
- スカラーの `add` の変更

## 失敗時

- `a` または `b` が長さ 2 の配列でない（配列でない、長さ不足・過多）: `TypeError` を投げる

## 例

| 操作または入力 | 期待結果 |
|---|---|
| `addVec([2, 3], [4, 5])` | `[6, 8]` |
| `addVec([-1.5, 0.5], [0.5, -0.5])` | `[-1, 0]` |
| `addVec([0, 0], [0, 0])` | `[0, 0]` |
| `addVec([-4, -6], [1, 2])` | `[-3, -4]` |
| `addVec([1, 2], [3])` | `TypeError` |
| `addVec([1, 2, 3], [4, 5, 6])` | `TypeError` |

## 完了条件

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. 交換法則が成り立つ。ゼロベクトル `[0, 0]` が単位元である。引数を変更しない。戻り値は入力とは別の新しい配列である。
