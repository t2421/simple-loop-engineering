# 計算ページへのベクトル足し算表示

既存の計算ページに、2 次元ベクトル足し算の入力・数値結果・SVG 矢印を追加する。

## 種別

機能追加

## 対象

- 場所: 計算 UI（`src/calc.html` / `src/calc.css` / `src/calc.mjs`）
- 公開面: ベクトル A・B の入力各 2、計算ボタン、数値結果、SVG 図

## 背景

`addVec` は `0050-math-vec-add` で公開する。ブラウザから 2 本のベクトルとその和を見て確認する画面が無い。見た目の正は次の Figma フレームとする。

`addVec` の実装は `0050-math-vec-add` の範囲である。この作業は公開済みの `addVec` を呼ぶ。

## 仕様

### 構造と操作

既存 Calculator カード内、既存の結果表示の下にベクトル用セクションを置く。既存の入力 2 欄・加減選択・Calculate・Result の DOM id と操作は変えない。

- 見出し。ベクトル加算であることが分かる
- ベクトル A: 数値入力 2。id は `vec-a-x` / `vec-a-y`
- ベクトル B: 数値入力 2。id は `vec-b-x` / `vec-b-y`
- 計算ボタン。id は `vec-add-calculate`
- 数値結果。id は `vec-add-result`。`role="status"` かつ `aria-live="polite"`。初期表示は `—`
- 図: SVG。id は `vec-add-canvas`。軸（x, y）を持つ。計算後はベクトル A・B・和の 3 本の矢印を描く

操作:

- ベクトル計算ボタンを押すと、入力 4 つを数値に変換し `addVec([ax, ay], [bx, by])` を呼ぶ
- 空欄・非数は既存スカラー計算機と同じく `0` とみなす（`parseFloat` が有限でなければ 0）
- 数値結果は `x, y` 形式（例: `6, 8`）。括弧は付けない
- SVG の原点はキャンバス中央。数学座標（y 上向き）を画面座標（y 下向き）に反転する。1 単位 = 1 CSS px。ベクトル `(x, y)` の終点は `(originX + x, originY - y)`
- 初期状態の SVG は軸のみ。ベクトル線は出さない
- 既存のスカラー Calculate はベクトル欄・ベクトル結果・SVG を動かさない。ベクトル計算はスカラー結果を動かさない

### 見た目

- トークンと幾何の正は `task/0051-calc-vec-add/calc-vec-add.figma.json`（ノード `2:5` から抽出したプロパティ）
- 参照画像の正は `task/0051-calc-vec-add/calc-vec-add.png`（同じノードの書き出し）
- 実装は CSS 変数でトークンを参照し、表に無いマジックナンバーを置かない
- 比較するプロパティは塗り、文字色、フォントサイズ、フォントウェイト、パディング、ギャップ、角丸、幅・高さとする

### 状態

- 通常（未計算）: 数値結果は `—`。SVG は軸のみ
- 計算後: 数値結果は `addVec` の戻り値を `x, y` 形式で表示する。SVG に A / B / 和の 3 本があり、stroke は抽出 JSON の色
- 空入力で計算: 両ベクトルを `[0, 0]` とみなし、数値結果は `0, 0`
- ホバー: 範囲外

## 範囲外

- `addVec` の実装（`0050-math-vec-add`）
- ベクトルの引き算・スカラー倍・3 次元
- 既存スカラー計算機の見た目・トークン・操作の変更
- ピクセル完全一致（差分 0）
- ホバー時の見た目
- 入力に応じた自動スケール（キャンバスから矢印がはみ出す場合もクリップしてよい。スケール変換はしない）

## 失敗時

なし。

## 例

| 操作または入力 | 期待結果 |
|---|---|
| A `(2, 3)`、B `(4, 5)`、ベクトル計算 | 数値結果 `6, 8`。SVG の和の終点は原点から画面座標 `(+6, -8)`（y 反転） |
| A `(-1.5, 0.5)`、B `(0.5, -0.5)`、ベクトル計算 | 数値結果 `-1, 0` |
| A `(0, 0)`、B `(0, 0)`、ベクトル計算 | 数値結果 `0, 0` |
| A `(-4, -6)`、B `(1, 2)`、ベクトル計算 | 数値結果 `-3, -4` |
| 左 `2`、右 `3`、足し算、Calculate（既存スカラー） | 既存どおり結果 `5`。ベクトル結果は変わらない |
