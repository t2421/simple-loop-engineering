# 進捗テンプレート

新しい進捗はこのファイルをコピーして `<...>` を埋める。  
**見出し名・順番は変えない。** メタ情報（Target Spec / Branch / PR / Status）も欠かさない。

チェックボックスの意味:

- `[ ]` 未着手
- `[/]` 進行中
- `[x]` 完了

試行ログは新しい行を末尾に足す。失敗と解消も残す。消して体裁を整えない。
