# `sub` の追加

2 つの数の差を返す `sub` を公開する。

## 種別

機能追加

## 対象

- 場所: 算術ライブラリ
- 公開面: `sub(a, b) -> number`

## 背景

差を返す公開関数が無い。四則演算のうち減算として、2 つの有限数の差を取る操作が必要である。

## 仕様

```
sub(a, b) -> number
```

- `a`: 被減数。有限数
- `b`: 減数。有限数
- 戻り値: `a` から `b` を引いた差。有限数
- 純関数。引数を変更しない。
- `a` と `b` は IEEE 754 の有限数である。`NaN` および `Infinity` は受け取らない。
- 戻り値は `a - b` に等しい。
- `0` は右単位元である: `sub(a, 0)` は `a` に等しい。
- 同じ数同士の差は `0` である: `sub(a, a)` は `0` に等しい。
- 交換法則は成り立たない。一般に `sub(a, b)` と `sub(b, a)` は等しくない。

## 範囲外

- `NaN` / `Infinity` の扱い
- 3 引数以上の差
- 既存の `add` の変更

## 失敗時

なし。

## 例

| 操作または入力 | 期待結果 |
|---|---|
| `sub(5, 3)` | `2` |
| `sub(-1.5, 0.5)` | `-2` |
| `sub(0, 0)` | `0` |
| `sub(-4, -6)` | `2` |

次をすべて満たしたとき、この仕様は完了とする。検証はこれらの条件に対して行い、テスト実行結果などのコマンド出力を根拠にする。

1. 「対象」が仕様どおりに公開または修正されている。
2. 「例」がすべて、テストまたは再現手順で同じ結果になる。
3. 「失敗時」に書いた入力・操作で、仕様どおり失敗する。該当がなければこの項は「なし」。
4. 「範囲外」を実装していない。
5. `0` が右単位元である。同じ数同士の差は `0` である。引数を変更しない。
